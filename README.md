# Traffic Monitor — MVP (Этап 1: только чтение)

Локальный VPN-монитор трафика для Android. На этом этапе приложение:

1. Поднимает `VpnService` и перехватывает весь IPv4-трафик устройства
2. Парсит IP/TCP/UDP-заголовки каждого пакета
3. Определяет, какое приложение отправило пакет (через `ConnectionOwnerUid`, API 29+)
4. Показывает список: приложение → куда стучится → сколько байт

**Важно:** пакеты пока НЕ пересылаются дальше в реальную сеть — только
логируются. Значит, пока сервис активен, интернет на устройстве работать
не будет. Это сделано намеренно, чтобы отладить перехват и парсинг отдельно
от NAT/форвардинга. Реальный доступ в сеть добавится на Этапе 2.

## Как запустить

1. Открыть проект в Android Studio (Koala или новее)
2. Дать Gradle синхронизироваться
3. Запустить на **физическом устройстве** (эмулятор тоже подойдёт, но VPN
   на эмуляторах иногда ведёт себя нестабильно)
4. Нажать "Запустить мониторинг" — появится системный диалог с запросом
   разрешения на создание VPN-соединения. Подтвердить
5. Открыть любое приложение, которое лезет в сеть (браузер, соцсеть) —
   в списке на экране появятся записи

## Структура

- `vpn/` — `VpnService`, чтение пакетов из tun-интерфейса
- `parser/` — разбор IPv4/TCP/UDP заголовков (без внешних библиотек)
- `resolver/` — сопоставление UID процесса с именем приложения
- `ui/` — единственный экран со списком соединений в реальном времени

## Известные ограничения MVP

- Только IPv4 (IPv6-пакеты парсер пропускает)
- Домены не резолвятся — видно только IP:порт (SNI/DNS-парсинг — следующий шаг)
- Список хранится в памяти, при перезапуске сервиса обнуляется (Room — на потом)
- Нет форвардинга трафика, соответственно нет и реальной блокировки —
  только наблюдение

## Следующие шаги (Этап 2 и 3)

1. Добавить `SocketForwarder`: разбирать TCP/UDP-сессии и форвардить их через
   обычные Java-сокеты (простой user-space NAT), чтобы устройство сохраняло
   доступ в интернет при активном сервисе
2. Добавить `DnsParser`/`TlsSniParser`, чтобы показывать домены, а не только IP
3. Добавить `BlockListStore` — переключатели по приложению в UI, при включении
   блокировки пакеты этого UID просто не форвардятся дальше
4. Перевести журнал соединений на Room, чтобы данные не терялись
